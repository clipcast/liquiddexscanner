# LiquidDexScanner

Real-time token explorer for [Liquid Protocol](https://github.com/Liquid-Protocol-Ops/SDK) on **Base Chain**.

Built with Next.js 14, viem, Liquid SDK, recharts, and Tailwind CSS.

## Features

- **New Tokens** — Real-time feed of all tokens deployed via Liquid Protocol
- **Trending** — Top tokens by market cap and volume
- **Chart** — Price chart + full contract info (Hook, Fee, Locker, Deployer)
- **Sniper Auction** — MEV auction state per pool
- **Vault & Airdrop** — Token lockup/vesting and airdrop info

## Run Locally

```bash
npm install
npm run dev
```
